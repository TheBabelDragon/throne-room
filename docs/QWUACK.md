# Qwuack

Stay on `main`.

`python -m observer.startup --full` starts the CSI conductor.
It does **not** start the Duck.

```bash
python -m qwuack.startup
python -m qwuack.startup --once
python -m qwuack.startup --body millennium --once
python -m qwuack.millennium --once --pond rh
```

You should immediately see `QWUACK STARTUP` and a pid.

Millennium Lab is documented in [`MILLENNIUM.md`](MILLENNIUM.md).
The Duck is rewarded for progress. It cannot declare a prize solved.
